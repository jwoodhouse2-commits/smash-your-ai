You've met three frameworks now. Here's a cheat sheet for when to reach for which.

## The decision tree

**Is this a short one-liner?**
→ Skip frameworks. Just ask.

**Do you already know what "good" looks like (you've got an example to point at)?**
→ Use **CARE**.

**Is this a message where the tone and audience matter as much as the content?**
→ Use **CO-STAR**.

**Is it anything else?**
→ Use **RTF**.

That's it. Print it on a sticky note if you want.

## Common situations mapped

### Writing tasks

| Task | Framework |
|---|---|
| One-off email reply | RTF |
| A tough client message | CO-STAR |
| LinkedIn post in your voice (you have past posts to reference) | CARE |
| Newsletter intro | RTF, then CARE if you want to sharpen |
| Cold outreach to a specific person | CO-STAR |

### Thinking tasks

| Task | Framework |
|---|---|
| Summarise this document | RTF |
| Brainstorm 20 ideas | RTF |
| Should I do X or Y? (business decision) | CO-STAR |
| Analyse these numbers | RTF |

### Building tasks

| Task | Framework |
|---|---|
| First draft of a proposal | CARE if you have past proposals to mirror |
| Job description | CO-STAR (audience matters a lot) |
| Instructions for a custom GPT | CO-STAR |
| Product description | CARE |

## The mixing principle

You don't have to pick just one. Real prompts often blend frameworks.

A very common combo: **CO-STAR + an example from CARE**.

```
# Context
[CO-STAR style context]

# Objective
[outcome]

# Style / Tone / Audience
[...]

# Response
[format]

Example of the output style I want:
[paste example]
```

Best of both worlds.

## What "fluent" looks like

After a few weeks of using frameworks consciously, you'll start doing three things automatically:

1. **Dropping in the role and context** without being prompted.
2. **Ending with "format as..."** because you know generic answers waste your time.
3. **Including an example when you've got one**, because you've learned how much it raises the bar.

You won't be writing *"# Context"* as headers any more. You'll just be writing good prompts.

That's the whole goal.
